# Apple JWS test certificates (test only)

Generated by `bash scripts/gen-test-certs.sh` (OpenSSL 3 or LibreSSL). **Test keys only — never use them anywhere
else.** They stand in for Apple's StoreKit signing chain in `supabase/tests/apple/**`:

| File | What it is |
|---|---|
| `root.*` | P-384 self-signed root, stand-in for Apple Root CA G3 (the tests pass it as the trusted root) |
| `intermediate.*` | P-384 CA signed by the root, with OID `1.2.840.113635.100.6.2.1` |
| `leaf.*` | P-256 leaf signed by the intermediate (ecdsa-with-SHA384), with OID `1.2.840.113635.100.6.11.1`; tests sign JWS with `leaf.key.pem` |
| `leaf_expired.crt.pem` | Same key and OID, valid 2020-01-01 – 2021-01-01 only |
| `leaf_no_oid.crt.pem` | Same key, no leaf OID |
| `intermediate_no_oid.crt.pem` | Same key and subject as `intermediate`, no intermediate OID |
| `rogue_*` | An independent chain with the same names and OIDs but its own root (wrong-root cases) |
| `test_p8.key.pem` | P-256 PKCS#8 key in the App Store Connect `.p8` format (ES256 JWT tests) |

All certificates except `leaf_expired` are valid 2025-01-01 – 2050-01-01. Keys are PKCS#8 PEM.
